# Спросить дорогу по-турецки — Alterna Türkçe

Урок турецкого (A1–A2): как спросить дорогу и понять ответ. Фразы с озвучкой, 3D-город Антальи с маршрутом, 3D-перекрёсток, три суффикса (-e / -de / -den) в конструкторе, квест по карте, карточки, тест + платформа Alterna Timur A0→C1.

Mobile-first, без сборки. 3D — three.js (CDN).
